# 🛍️ Customer Segmentation using K-Means Clustering

## 📌 Project Overview
This project performs Customer Segmentation using the K-Means Clustering algorithm.  
The goal is to group mall customers based on their Annual Income and Spending Score to identify different customer segments for business analysis and marketing strategies.

---

## 🚀 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📂 Dataset
Dataset used: `Mall_Customers.csv`

Features Used:
- Annual Income (k$)
- Spending Score (1-100)

---

## ⚙️ Project Workflow
1. Import required libraries
2. Load and explore dataset
3. Check missing values
4. Select important features
5. Scale the dataset using StandardScaler
6. Find optimal clusters using Elbow Method
7. Apply K-Means Clustering
8. Visualize customer segments
9. Analyze cluster distributions
10. Save final clustered dataset

---
